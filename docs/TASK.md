# Tareas del Proyecto - StickerHub

## 1. Configuración Inicial
- [ ] Crear proyecto Next.js con TypeScript y Tailwind CSS.
- [ ] Configurar `docker-compose.yml` para base de datos MySQL.
- [ ] Inicializar Prisma y conectar con MySQL.

## 2. Base de Datos
- [ ] Definir modelos en `schema.prisma` (ej. `Album`, `Sticker`).
- [ ] Generar y ejecutar migraciones de base de datos.

## 3. Backend (API REST en Next.js)
- [ ] Endpoints CRUD para Álbumes (`/api/albums`).
- [ ] Endpoints CRUD para Láminas/Stickers (`/api/stickers`).
- [ ] Lógica para calcular faltantes y repetidas.

## 4. Frontend
- [ ] Crear Layout y navegación básica.
- [ ] Pantalla principal: Listado de álbumes y botón crear.
- [ ] Pantalla de álbum: Grid de láminas con cambio de estado (tengo, falta, repetida).
- [ ] Integración Frontend - API.

## 5. Pruebas y Despliegue
- [ ] Probar flujos de API usando Postman.
- [ ] Revisión de diseño responsivo.
- [ ] Commit final GitHub.
