# StickerHub - Project Brief

## Proyecto
Aplicación web (Backend + Frontend) para gestión de láminas de álbumes.

## Objetivo
Permitir a los usuarios crear álbumes, registrar láminas y controlar su inventario (obtenidas, faltantes, repetidas).

## Funcionalidades
- Creación de álbumes.
- Registro de láminas por álbum.
- Control de estado: obtenidas, faltantes, repetidas.

## Stack Tecnológico
- **Frontend y API REST:** Next.js
- **Lenguaje:** TypeScript
- **ORM:** Prisma
- **Base de Datos:** MySQL
- **Diseño:** Tailwind CSS

## Infraestructura y Herramientas
- **Entorno de desarrollo:** Docker + Docker Compose
- **Pruebas de API:** Postman
- **Control de versiones:** Git / GitHub
